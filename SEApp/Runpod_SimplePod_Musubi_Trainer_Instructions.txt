Upload zip file into workspace and extract there or extract in your system and upload all files into workspace

Start a new terminal

To install run below command

export UV_THREADPOOL_SIZE=8
pip install huggingface_hub hf_xet hf_transfer requests
export HF_HOME="/workspace"
chmod +x RunPod_Install_Musubi_Trainer.sh
./RunPod_Install_Musubi_Trainer.sh

To automatically download training models into /workspace folder open a new terminal in the folder and execute below commands

You can run this command same time as installation with opening another terminal

Then download models (choose which model you want):

apt clean
rm -rf /var/cache/apt/archives/*
apt update
apt install -y aria2
pip install huggingface_hub hf_xet hf_transfer requests
python Download_Train_Models.py

This above command will ask you which model to download choose from menu

Option 13 downloads Ideogram 4 into Training_Models_Ideogram_4.

Option 14 downloads Krea 2 into Training_Models_Krea_2. The source file raw.safetensors is saved as Krea_2_Raw_Base.safetensors.

To run the app again after installation later run below command - installation will auto start the app so use this later for re-starting the app

cd /workspace/SECourses_Musubi_Trainer
git pull
source venv/bin/activate
